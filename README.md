# DJI Osmo Action 4 · 3D 实机拆解

基于 DJI 官方 Osmo Action 4 3D 模型制作的交互式拆解页面。镜头、前后屏、电池仓保护盖、USB-C 充电口盖、电源键、顶部按键与磁吸底座均为实机网格，可直接点击拆装。

内部电池、主板、影像传感器、扬声器与接口组件为按实机比例重建的展示结构，用于拆解后的内部透视。

## 本地预览

在本目录启动任意静态文件服务器，例如：

```bash
python -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。

## 功能

- 官方 GLB 实机外观，非程序化近似模型
- 10 个真实外观模块，一键拆解 / 组装
- 拆开后自动进入 X-RAY 内胆视图，显示 1770 mAh 电池、主板、CMOS 传感器、扬声器与接口组件
- 点击或悬停部件查看参数
- 桌面与移动端适配
- Three.js 与模型资源均随仓库提供，不依赖 CDN
